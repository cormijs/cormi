# @cormijs/plugin-antd

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-antd/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-antd)

Ant Design for Cormi apps: theme, locale, and server-rendered styles

```sh
pnpm add @cormijs/plugin-antd
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-antd'
```

支持的打包器：不限；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
