# @cormijs/plugin-legacy

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-legacy/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-legacy)

Legacy browsers for Cormi apps, with @vitejs/plugin-legacy

```sh
pnpm add @cormijs/plugin-legacy
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-legacy'
```

支持的打包器：Vite；支持的 UI 框架：不限。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
