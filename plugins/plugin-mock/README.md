# @cormijs/plugin-mock

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-mock/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-mock)

Mocked API routes for Cormi apps in dev mode

```sh
pnpm add @cormijs/plugin-mock
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-mock'
```

支持的打包器：不限；支持的 UI 框架：不限。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
