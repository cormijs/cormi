# @cormijs/plugin-dva

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-dva/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-dva)

dva for Cormi apps: redux and redux-saga with models of src/models

```sh
pnpm add @cormijs/plugin-dva
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-dva'
```

支持的打包器：不限；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
