# @cormijs/plugin-export-static

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-export-static/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-export-static)

Pre-render the pages of Cormi apps into HTML files for static hosts

```sh
pnpm add @cormijs/plugin-export-static
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-export-static'
```

支持的打包器：不限；支持的 UI 框架：不限。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
