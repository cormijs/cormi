# @cormijs/plugin-tailwindcss

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-tailwindcss/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-tailwindcss)

Tailwind CSS v4 for Cormi apps

```sh
pnpm add @cormijs/plugin-tailwindcss
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-tailwindcss'
```

支持的打包器：Vite · Rsbuild；支持的 UI 框架：不限。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
