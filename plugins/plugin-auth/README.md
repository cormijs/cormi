# @cormijs/plugin-auth

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-auth/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-auth)

Signed-in users for Cormi apps: ctx.auth.login(), state.user, routes that require a user, password hashing

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [会话、鉴权与常用中间件](https://cormi.js.org/guide/auth)。
