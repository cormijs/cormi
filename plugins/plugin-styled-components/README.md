# @cormijs/plugin-styled-components

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-styled-components/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-styled-components)

styled-components for Cormi apps: theme and server-rendered styles

```sh
pnpm add @cormijs/plugin-styled-components
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-styled-components'
```

支持的打包器：Vite；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
