# @cormijs/plugin-initial-state

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-initial-state/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-initial-state)

The initial state of Cormi apps, provided by runtime plugins through an event

```sh
pnpm add @cormijs/plugin-initial-state
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-initial-state'
```

支持的打包器：不限；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
