# @cormijs/plugin-layout

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-layout/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-layout)

A layout with a menu built from the routes, for Cormi apps, with Ant Design

```sh
pnpm add @cormijs/plugin-layout
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-layout'
```

支持的打包器：不限；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
