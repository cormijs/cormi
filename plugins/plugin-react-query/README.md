# @cormijs/plugin-react-query

[![npm](https://img.shields.io/npm/v/@cormijs/plugin-react-query/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/plugin-react-query)

TanStack Query for Cormi apps

```sh
pnpm add @cormijs/plugin-react-query
```

```yaml
# cormi.yml
- name: '@cormijs/plugin-react-query'
```

支持的打包器：不限；支持的 UI 框架：React。

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
