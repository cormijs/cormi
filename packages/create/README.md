# @cormijs/create

[![npm](https://img.shields.io/npm/v/@cormijs/create/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/create)

Create a Cormi app: a frontend, a backend, both, or pages rendered on the server

```sh
pnpm create @cormijs my-app
npm create @cormijs my-app
pnpm create @cormijs my-app --template ssr --ui vue --bundler rsbuild --database postgres
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [快速开始](https://cormi.js.org/guide/getting-started)。
