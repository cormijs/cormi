# @cormijs/cache-redis

[![npm](https://img.shields.io/npm/v/@cormijs/cache-redis/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/cache-redis)

The cache of a Cormi app (ctx.cache) in Redis

```yaml
- name: '@cormijs/cache-redis'
  config:
    url: !!js process.env.REDIS_URL
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [缓存](https://cormi.js.org/guide/cache)。
