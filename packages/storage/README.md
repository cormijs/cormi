# @cormijs/storage

[![npm](https://img.shields.io/npm/v/@cormijs/storage/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/storage)

The file storage of a Cormi app (ctx.storage): files by key, on the local disk; S3 with @cormijs/storage-s3

```yaml
- name: '@cormijs/storage'
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [文件存储](https://cormi.js.org/guide/storage)。
