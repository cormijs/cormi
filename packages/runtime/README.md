# @cormijs/runtime

[![npm](https://img.shields.io/npm/v/@cormijs/runtime/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/runtime)

The browser runtime of Cormi without a UI framework: the cordis context, the app's lifecycle, the route table and the loader protocol

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的前端全栈框架。文档见 [docs](https://github.com/cormijs/cormi/tree/main/docs)。
