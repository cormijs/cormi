# @cormijs/cache-database

[![npm](https://img.shields.io/npm/v/@cormijs/cache-database/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/cache-database)

The cache of a Cormi app (ctx.cache) in its database, with @cormijs/database

```yaml
- name: '@cormijs/database'
- name: '@minatojs/driver-sqlite'
  config:
    path: data/app.db
- name: '@cormijs/cache-database'
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [缓存](https://cormi.js.org/guide/cache)。
