# @cormijs/database

[![npm](https://img.shields.io/npm/v/@cormijs/database/next?style=flat-square)](https://www.npmjs.com/package/@cormijs/database)

The database of a Cormi app: minato's ctx.model and ctx.database, with any minato driver

```yaml
- name: '@cormijs/database'
- name: '@minatojs/driver-sqlite'
  config:
    path: data/app.db
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [数据库](https://cormi.js.org/guide/database)。
