# @cormijs/ai-openai

The AI service of a Cormi app (`ctx.ai`) backed by OpenAI or an OpenAI-compatible endpoint (DeepSeek, Qwen, Ollama, vLLM, OpenRouter).

```yaml
- name: '@cormijs/ai-openai'
  config:
    baseURL: https://api.openai.com/v1
    model: gpt-4o-mini
```

这是 [Cormi](https://github.com/cormijs/cormi) 的一部分：以 Cordis 为插件宿主的全栈框架。文档见 [AI Native 与 `@cormijs/ai`](https://cormi.js.org/guide/ai)。
